# 🦷 Dental Appointment System

A full-stack dental appointment booking platform that streamlines appointment scheduling, patient management, and communication between patients and dental clinics.

## 🚀 Live Demo

🌐 **Live Website:** https://manash-dental-care.netlify.app/

---

## 📖 Overview

Dental Appointment System is a modern web application designed to simplify the process of booking and managing dental appointments online.

Patients can schedule appointments through an intuitive interface, while the backend handles appointment management, database operations, and automated email confirmations.

This project demonstrates full-stack web development concepts including frontend development, backend API design, database integration, and email automation.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/manashwebdev/Manash-dental-care.git
```

Navigate to the project directory:

```bash
cd Manash-dental-care
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
